## 1. 목적과 독자
| 항목 | 방침 |
|---|---|
| 목적 | 얼굴 부위의 디테일(눈 모양·눈 칠하기·표정·코·귀·입·머리카락)을 실험으로 익히고, 그 원리를 AI 디테일 문장·칠하기 문장·가림 영역으로 옮겨 **실제 그림까지 만들어 보게** 한다 |
| 독자 | 그림과 AI를 처음 접하는 비전공자. 수식이 어려운 사람도 끝까지 읽을 수 있어야 한다 |

| 스킬 | 연구실 해설 스킬 `ai-lab-explainer-plain`(원리 먼저 교수법 P1~P7 내장)의 틀을 따른다 |
| 앞 편 | 03 얼굴 편(얼굴 비율), 01 옷장 편, 첫 시리즈. 안 봐도 읽히도록 낱말을 다시 설명한다 |

## 2. 원자료와 저작권
1. 원리는 KawaiiSensei 『いいトコどり! 人物パーツの描き方』(マイナビ出版, 2023) **1장 「顔を描こう」(p.12~46)** 을 참고한다.
2. 책의 **그림·문장·도식·색 값(RGB)·구성 순서는 옮기지 않는다**. 원리만 가져와 연구실 캐릭터와 직접 움직이는 실험으로 새로 만든다. 페이지의 색 값은 새로 정한 예시다.
3. 얼굴 전체의 비율·각도(정면·옆·비스듬히·올려다보기·내려다보기, 남녀 차이)는 03 얼굴 편과 겹치므로 이 편에서는 부위의 디테일만 다룬다.
4. 책의 칼럼 가운데 입술을 성적으로 강조하는 내용, 송곳니·혀를 과장한 그림은 다루지 않는다. 귀걸이는 시아의 고정 장식 정도로만 언급한다.
5. 사용자가 함께 준 2차 창작 설정 시트(유명 캐릭터)는 **한 장에 얼굴 각도·표정을 모으는 형식만** 참고하고, 캐릭터 디자인은 쓰지 않는다(5부 하루 설정 시트).
6. 원자료 출처는 목차 '원리와 출처', 바닥글, README에 모두 밝힌다.

## 4. 등장인물
- 모델: 모아(1부), 하루(2부), 시아와 박사(3부), 하루·시아·모아(4부), 모두(5부). 화가: 주판봇(동그라미·가닥·순백부터 서두르다 틀림) · 초파리(꼭짓점·덩어리·순서부터 의심해 맞힘). 평가단 X1·X2·X3(닮음·원리·자연스러움). 해설 박사, 수식 질문 조수 하루.
- **하루·시아·모아는 20대 성인, 박사는 30대 성인 남성.** 어려 보이는 얼굴·노출·교복 느낌은 쓰지 않는다. 표정·큰 웃음·반짝이는 눈 요청에서 생기는 나이 쏠림은 6부 drift에서 막는 법을 다룬다.
- 외형 고정값: 하루(정수리 번 2개 + 앞머리 가운데 남색 줄), 시아(흑발, 장식 없음, 작은 은색 귀걸이), 모아(흰 프릴 머리띠 + 왼쪽 귀 위 흰 리본), 박사(흰 줄 있는 짙은 머리, 굵은 눈썹, 청록 사각 안경). 표정 그림은 `fruitfly-lab-expressions`.

## 5~7. 한 부의 순서 · 단계 틀 · 문장 규칙
01·03편 방침과 같다.
- 한 부: 픽셀 표지 → 세 줄 요약 + 낱말 풀이 → 오늘의 과제 → 단계 1~4 → 프롬프트로 직접 만들어 보기 → 프롬프트 연습 과제 → 평가 → 정리 → 다음으로 → 지식 색인·꾸러미·바닥글.
- 단계: 제목(결과를 우리말 문장으로) → 왜 이렇게 하나 → 수식 상자(필요할 때만, **말로 하면 → 숫자 3줄 → 학교 수학 → 식 → 조각 → 한마디**) → 일상/현장 → 대화 4줄 → 실험 패널 → 풀이 3줄 → 그림 → AI 결과 그대로 써도 될까? → 주의할 점 → 3지선다 퀴즈.
- 수식 상자를 둔 단계: 1-1(atan 기울기), 1-3(cos 비율), 2-2(곱하기·더하기), 3-2(sin 귀 너비), 3-3(sin 이줄 깊이), 4-1(넓이 k²), 5-3(가림 몫 %).
- 숫자는 `build/check_numbers.py`로 검산하고, 예시값은 본문과 바닥글에 예시값이라고 밝힌다.
- 우리말 어순, 사물 주어 문장 금지, '칸·사다리·관통' 금지, 독자를 수학·통계를 포기한 사람으로 부르는 줄임말 금지.

## 8. 프롬프트로 직접 만들어 보기 · 연습 과제
- A = `build/make_requests.py`의 프롬프트(원본), B = 'Same image, keep the same framing. Change only: …' 한 가지 변화. 부마다 2개. 6부는 실패 그림을 **고치는** B(f2는 부분 수정, f7은 칠하기 조각).
- **실제 결과**는 그림을 받은 뒤 A·B를 나란히 보고 적는다. 받기 전에는 '아직 만들지 않음'을 그대로 적는다(`content_make.py`의 `RES`).
- 새 대화에서 만드는 B는 'Same image'로 시작하는 문장만 넣지 않는다. A 프롬프트 안의 해당 문장을 직접 고쳐 한 덩어리로 넣고 참고 그림을 첨부한다(v1.1 실습 1·2 B에서 캐릭터가 사라지고 실사 사진이 나온 실제 결과).
- 연습 과제(`content_drill.py`)는 부마다 5개(v1.0 2개 + v1.2 3개), 예상 결과 그림 36장. 1~5부의 모든 단계에 단계 그림을 하나씩 둔다(v1.2). **03 얼굴 편의 3차 시도에서 효과가 있던 방법을 처음부터 반영한다**: ① 비교할 두 그림은 서로 다른 새 대화 ② 여러 얼굴 시트보다 한 장 ③ 바뀌는 곳은 'most important'로 표시하고 과장 ④ 바로잡을 실패 그림은 첨부하지 않기.
- 1차 결과가 실패하면 03편처럼 1차 결과를 남기고 '다시 시도'(`RETRY`)·'3차 시도'(`RETRY3`)를 붙인다(지금은 비어 있음).
