# M02 · 2부 '직접 만들어 보기' 비교 그림

**Genspark에 먼저 붙여 넣기 ↓**
```
해설 페이지의 '직접 만들어 보기' 비교 그림을 만들어 줘.
- 첨부한 그림(이미 만든 A 결과)과 똑같은 캐릭터·구도·화풍·빛을 유지하고, 아래 'Change only'에 적힌 것만 바꿀 것
- 비율은 첨부한 A 결과와 같게
- 등장인물은 모두 20대 성인(박사는 30대 성인 남성). 노출·교복 느낌·어려 보이는 얼굴 금지
- 그림 안에 글자·숫자·로고 금지
```

## p2_haru_eye_paint_b — 레이어로 칠한 하루의 눈
첨부: p2_haru_eye_paint.png (A 결과) + refs/moa_anime_base.png, refs/moa_sheet.png, refs/haru_anime_base.png, refs/sia_anime_base.png, refs/doctor_sheet.png
방법: A 결과를 첨부하고 Change only 문장으로
```
Same image, keep the same framing. Change only: make the whites of the eyes pure bright white and the irises one flat blue with no shadow and no glow, a single highlight. Still no text.
```

Same image, keep the same framing. Change only: give all six faces the same flat neutral eyebrows; keep the eyes and mouths as they are. Still no text.
